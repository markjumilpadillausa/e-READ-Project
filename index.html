Learners earn one star for every practice word read correctly, every reading assessment task finished, and every game level passed.

    Assessment Details

    Task 1: Letter Names

    Tick when the learner names the letter. The list is in the same order the learner sees, and each number matches the card number on the learner's screen. The timer on the side starts on your first tick.

    Task 2: Letter Sounds

    Tick when the learner gives the letter sound. The letters are shuffled again for this task, so the order is different from Task 1.

    Task 3: Reading Words by Pattern

    Tick each word read correctly. The patterns go from simplest to hardest, and the words are shuffled only within their own pattern. The small number on each word matches the card number on the learner's screen. The timer starts on your first tick.

    Advisers

    Every new adviser starts with the PIN admin. They sign in with their DepEd email and admin, then the system asks them to make their own 4 number PIN. If an adviser forgets it, tap Reset PIN and then Save Advisers, and their PIN goes back to admin. Results are emailed to the adviser of each grade. When a grade has two or more advisers, choose each learner's adviser in the Learner List. Give each adviser a PIN so they can sign in and review practice recordings.

    Adviser Sign In Details

    Only you can see this. Use it when an adviser forgets their email or PIN. Tap Show Message to get a ready message you can copy and send to the adviser.

    Upload LRNs

    Copy from Excel or Google Sheets and paste below, one learner per line in this order: LRN, Last name, First name, Grade, Section (Section is needed only for Grade 4: Diamond or Emerald). Names already on the list get their LRN. New names are added. In Excel, set the LRN column to Text first so the numbers stay complete.

    Start Fresh

    Printable Materials for the Learner

    Print these so the learner reads from paper while you tick on your device. Each card fits on one A4 sheet. The word cards show words only, with no pattern names. Collect the cards after each assessment.

    When a learner reads from these printed cards, set Learner Reads From to Printed Card in the assessment form so your tick sheet follows the same order.
